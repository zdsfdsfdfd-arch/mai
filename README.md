# ФБСР — Цифровой портал (демо)

Статический сайт федерации боевого самбо в стиле утверждённого макета: тёмная тема, крупная
типографика, красный акцент, hero-сцена «в движении». Без сборки и без зависимостей — обычные
HTML/CSS/JS, работают с любого хостинга в РФ (nginx, Apache, reg.ru, Timeweb, Selectel и т. п.).

## Структура

```
index.html            Главная (hero, календарь, цифры, рейтинг, новости, медиа, партнёры)
competitions.html     Соревнования: календарь с фильтрами, результаты, регламенты
athletes.html         Спортсмены: рейтинг с фильтрами, весовые категории
clubs.html            Клубы: поиск по городу/региону, карта (заглушка), заявка на аккредитацию
teams.html            Сборные: составы (табы), тренерский штаб, сборы
federation.html       Федерация: о нас, история, структура, регионы, документы, контакты
media.html            Медиа: фото, видео, пресс-центр, аккредитация СМИ
privacy.html          Политика в отношении обработки персональных данных (152-ФЗ)
cookies.html          Политика использования cookie
consent.html          Согласие на обработку персональных данных (для форм)
terms.html            Пользовательское соглашение
404.html              Страница ошибки
assets/css/main.css   Все стили (дизайн-токены в :root)
assets/js/main.js     Навигация, параллакс hero, фильтры, табы, поиск ⌘K, демо-формы
assets/js/cookies.js  Менеджер cookie-согласий, подключение Яндекс.Метрики после согласия
assets/js/search-index.js  Индекс поиска по разделам
assets/img/hero-kick.png      Вырезанное фото (удар) для hero главной
assets/img/hero-throw.png     Вырезанное фото (бросок) для шапки раздела «Соревнования»
assets/img/photos/            Исходные фото для карточек и галереи
assets/img/og.png     Картинка для соцсетей (1200×630)
assets/fonts/         Шрифты Sofia Sans Condensed и Inter (самохостинг, без обращений к Google)
deploy/nginx.conf.example  Пример конфигурации nginx (HTTPS, кэш, CSP, красивые URL)
```

## Как заменить иллюстрацию на главной

Сцена на главной — фото удара ногой с удалённым фоном и постерной обработкой (`assets/img/hero-kick.png`),
в шапке раздела «Соревнования» — фото броска (`assets/img/hero-throw.png`). Чтобы заменить:

1. Подготовьте PNG **с прозрачным фоном** (вырезанные спортсмены). Чем выше разрешение, тем лучше:
   текущие исходники 720 px и 480 px по ширине, для больших экранов желательно от 1500 px.
2. Положите файл в `assets/img/` и замените `src` у `<img>` внутри `.hero__art` (главная) или
   `.page-hero__art` (соревнования). Пропорции заданы в `main.css` через `aspect-ratio`.
3. При необходимости подвиньте сцену: в `main.css` правила `.hero__art { left; top; height }`.

Фотографии из поисковой выдачи принадлежат правообладателям: перед запуском убедитесь, что у
федерации есть право на публикацию этих снимков, или замените их на собственную съёмку.

## Cookie и персональные данные (152-ФЗ)

* Баннер показывается при первом визите: «Принять все», «Только необходимые», «Настроить».
* Выбор хранится в cookie `fbsr_consent` (365 дней) и дублируется в localStorage.
* Яндекс.Метрика подключается **только** после согласия на аналитические cookie.
  Номер счётчика задаётся в каждой странице в блоке `window.FBSR_CONFIG = { metrikaId: 12345678 }`.
* «Настройки cookie» в подвале позволяют изменить или отозвать выбор в любой момент.
* Все формы содержат обязательный чекбокс согласия со ссылками на `consent.html` и `privacy.html`.
* Шрифты, стили и скрипты отдаются с сайта; внешние обращения (кроме Метрики после согласия) отсутствуют.

### Что заполнить перед запуском

В юридических страницах и подвале поля отмечены красным пунктиром (`class="placeholder"`):
наименование оператора, ОГРН/ИНН/КПП, юридический адрес, e-mail для обращений по ПД, дата утверждения,
домен. После заполнения уберите класс `placeholder`. Рекомендуем согласовать тексты с юристом.

Чек-лист для работы в РФ:

1. Хостинг и базы данных — на территории РФ (ч. 5 ст. 18 152-ФЗ).
2. Уведомление Роскомнадзора об обработке персональных данных (если ещё не подано).
3. Назначить ответственного за обработку ПД, указать его в `privacy.html`.
4. Для публикации данных спортсменов — согласие на распространение ПД по форме РКН.
5. При подключении бэкенда для форм — передача по HTTPS, журналирование согласий (дата, IP, текст).
6. Заменить `https://example.ru` в `robots.txt`, `sitemap.xml`, `deploy/nginx.conf.example` и в мета-теге `og:image` на всех страницах.

## Демо-данные

Спортсмены, клубы, результаты, новости и цифры — вымышленные, для демонстрации интерфейса.
Формы работают в демо-режиме (показывают сообщение об отправке без запроса на сервер).

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки поиска и cookie удобнее поднять сервер:

```
npx http-server -p 8080 .
```
