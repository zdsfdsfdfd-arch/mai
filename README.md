# История возникновения Lean Production

Интерактивная веб-презентация из 12 слайдов: как из производственной системы Toyota
выросло бережливое производство — от конвейера Генри Форда (1913) до «умных» заводов 2020-х.

Рассчитана на показ в формате **1920×1080** (полный экран на проекторе или ТВ),
но масштабируется под любой экран, включая ноутбук, планшет и телефон.

## Быстрый показ без установки

Готовая сборка уже лежит в папке `dist/`: скачайте репозиторий (Code → Download ZIP),
распакуйте и откройте `dist/index.html` двойным щелчком.

## Запуск

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
```

Сборка для показа:

```bash
npm run build      # готовая презентация в папке dist/
npm run preview    # открыть собранную версию: http://localhost:4173
```

Папка `dist/` самодостаточна: шрифты и фотографии лежат внутри, интернет на показе не нужен.
Её можно скопировать на флешку и открыть двойным щелчком по `dist/index.html`
(проверено в Chrome), положить на любой статический хостинг или открыть через `npm run preview`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Следующий слайд | `→` · `Пробел` · `PgDn` · свайп влево |
| Предыдущий слайд | `←` · `Shift+Пробел` · `PgUp` · свайп вправо |
| Первый / последний | `Home` · `End` |
| Содержание (переход к любому слайду) | `O` или `Esc` |
| Заметки докладчика | `N` |
| Полный экран | `F` |
| Источники фотографий | `I` |
| Подсказка по клавишам | `H` или `?` |

Буквенные клавиши работают и в русской раскладке. Ссылка на конкретный слайд: `#slide-6`.

На слайде 6 (Toyota Production System) два шага: «Люди» и «Два столпа» — стрелка `→`
сначала переключает шаг, затем ведёт к следующему слайду. Карточки на слайде 7
(«7 видов потерь») раскрываются по клику и показывают пример из жизни.

### Как устроен слайд

Каждый слайд — модуль, который экспортирует объект:

```js
export default {
  id: 'ford',                 // класс .slide--ford для стилей
  chapter: 'Генри Форд',      // подпись в верхней панели и в содержании
  title: 'Генри Форд и массовое производство',
  theme: 'dark',              // 'dark' или 'light'
  steps: 1,                   // необязательно: шаги внутри слайда
  notes: `Текст для докладчика`,
  html: ({ img }) => `...`,   // разметка; img('key') вставляет фото из data/images.js
};
```

Анимации задаются атрибутами, без JavaScript:

- `data-r` — элемент появляется при открытии слайда (`fade`, `left`, `right`, `scale`, `blur`, `mask`, `mask-up`);
- `style="--i:3"` — порядок появления (каждый шаг — 80 мс);
- `class="draw"` + `pathLength="1"` у SVG-линий — линия «прорисовывается»;
- `data-count="2685"` — число отсчитывается до значения;
- `class="kb"` у контейнера фото — медленное приближение (эффект Кена Бёрнса).

## Дизайн

- **Концепция «Поток»**: тонкая красная линия производственного потока проходит через всю
  презентацию — на обложке, в схемах, таймлайнах и финальной цепочке.
- **Цвета**: чёрный, белый, холодные серые и один сигнальный цвет — киноварь `#EC4219`
  (цвет японских печатей и сигнальной лампы «андон»).
- **Шрифты**: Geologica (заголовки и крупные цифры), Golos Text (текст), JetBrains Mono
  (подписи и даты), Shippori Mincho (японские надписи).
- **Фото**: исторические снимки в ч/б с плёночным зерном, современные — приглушённые.
- Учитывается системная настройка «уменьшить движение» (`prefers-reduced-motion`).

## Проверка

```bash
npm run build
npm run check                      # нужен Playwright: npm i -D playwright && npx playwright install chromium
SHOTS=screenshots npm run check    # + скриншоты всех слайдов
```

Скрипт открывает каждый слайд в 1920×1080 и сообщает об ошибках в консоли, незагруженных
изображениях и тексте, который выходит за безопасную зону или обрезается.
