# Папка для APK-файлов владельца

Положите сюда установщики приложений (`*.apk`), которые должны быть на телевизоре: YouTube, Netflix, HBO Max,
Apple TV, Spotify, Happ, Twitch, Rutube, VK Видео, Chrome и любые другие. Затем запустите `APPS.cmd`
(или `FULL.cmd` / `START.cmd` — они установят содержимое этой папки сами, если тут есть APK).

Проект ничего не скачивает: берите установщики из официальных источников (сайт разработчика, магазин
приложений телевизора). Файлы в этой папке в репозиторий не попадают (`.gitignore`).

Что происходит дальше: ClearTV следит за установкой приложений и, пока порядок главного ряда автоматический,
ставит приложения из списка предпочтений первыми — в порядке `scripts/data/preferred-apps.json`
(тот же список в `app/src/main/res/values/favorites.xml`). Эти приложения `clean.ps1` никогда не отключает.

Честно о совместимости: Netflix, HBO Max и Apple TV проверяют сертификацию устройства и DRM; на Салют ТВ
они могут не запуститься или работать с ограничениями. Это ограничение самих сервисов, а не лаунчера.
