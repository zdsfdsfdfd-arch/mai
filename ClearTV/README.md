# ClearTV — минималистичный домашний экран для СберТВ (Салют ТВ) и Android TV

ClearTV — альтернативное HOME-приложение (лаунчер) для телевизора в духе Apple TV, как в ролике
«Превращаю СберТВ в Apple TV»: чёрный экран, приветствие, тонкие часы и дата, три «пилюли» (Источники HDMI,
сеть, Настройки), имя выбранного приложения над доком, док в скруглённой полосе, мягкое свечение в цвете
приложения, сетка всех приложений по кнопке ▼, заставка-часы. Без рекламы, рекомендаций и навязанного контента.
Управление только пультом (D-pad), фокус виден с дивана.

> Честный статус проекта на момент публикации: **исходный код написан, APK собран и подписан, unit-тесты,
> тест встроенного ADB-клиента и тесты скриптов выполнены в облачной среде разработки. На реальном телевизоре
> приложение ещё не запускалось** — среда разработки не имеет доступа к вашему телевизору. Все проверки на
> устройстве (`scripts/verify.ps1`) выполняются на ПК с Windows рядом с телевизором (`START.cmd` / `FULL.cmd`).
> Подробно, что проверено и где: `docs/testing.md`.

Ориентир — ролик «Превращаю СберТВ в Apple TV» (Overtake lab): чистый главный экран без рекламы Сбера.
Что для этого делает проект: ClearTV как HOME (штатным механизмом), отключение рекламы и телеметрии Сбера по
базе, подтверждённой отчётами с реальных Салют ТВ (`scripts/data/salute-packages.json`, источники в
`docs/THIRD-PARTY.md`), заставка без промо, и два механизма против возврата штатного лаунчера после перезагрузки
(прошивка Сбера возвращает его при каждой загрузке): «хранитель» HOME через ADB на самом ТВ и служба спец.
возможностей.

## Быстрый старт (Windows 11, PowerShell)

1. На телевизоре включите отладку по сети (ADB): `docs/connect-tv.md`.
2. Диагностика и снимок состояния **до любых изменений**:
   ```powershell
   .\scripts\diagnose.ps1 -Ip 192.168.1.50
   ```
   Результат: `reports\device-report.md`, `reports\inventory.md`, `reports\backup\<время>\`.
3. Сборка APK (нужна JDK 17+; SDK скачается с официального сайта по флагу `-InstallSdk`):
   ```powershell
   .\scripts\build.ps1 -InstallSdk
   ```
   Можно пропустить и использовать готовый `dist\ClearTV-0.2.1-debug.apk` (собран без SDK, см. `reports\build-report-nosdk.md`).
4. Установка и запуск вручную (ClearTV появится и в списке приложений штатного лаунчера):
   ```powershell
   .\scripts\install.ps1 -Ip 192.168.1.50
   ```
5. Проверка на телевизоре:
   ```powershell
   .\scripts\verify.ps1 -Ip 192.168.1.50
   ```
6. Только после успешной проверки — назначить главным экраном (через штатный механизм `cmd package set-home-activity`, с подтверждением и записью в журнал):
   ```powershell
   .\scripts\install.ps1 -Ip 192.168.1.50 -SetHome
   ```
7. Откат в любой момент:
   ```powershell
   .\scripts\restore.ps1 -Ip 192.168.1.50
   ```

Если на ПК действует политика выполнения скриптов: `powershell -ExecutionPolicy Bypass -File .\scripts\diagnose.ps1 -Ip ...`.

## Управление пультом

| Кнопка | Действие |
|---|---|
| ◀ ▶ ▲ | перемещение фокуса между плитками дока и «пилюлями» сверху |
| ▼ (с дока) | сетка всех приложений; ▲ в её первом ряду возвращает док |
| OK | открыть приложение / источник / пункт настроек |
| OK (долгое нажатие) | меню плитки: Открыть, Переместить, Убрать/Добавить на главный экран, Скрыть, О приложении, Удалить |
| MENU | панель настроек (также шестерёнка в правом верхнем углу) |
| Назад | закрыть панель/экран «Все приложения», отменить перемещение; на главном экране — ничего |
| HOME | если ClearTV назначен главным экраном — возврат к первой плитке |

Режим перемещения: ◀ ▶ двигают плитку, OK сохраняет, Назад отменяет.

## Приложения владельца (папка `apps\`, `APPS.cmd`)

Список приложений, которые должны быть на главном экране, задан в `app/src/main/res/values/favorites.xml`
(зеркало — `scripts/data/preferred-apps.json`): YouTube, Netflix, HBO Max, Apple TV, Spotify, Happ, Twitch,
Rutube, VK Видео, Chrome. Пока порядок ряда автоматический (владелец ничего не переставлял), установленные из
списка идут первыми в этом порядке, затем приложения, установленные пользователем, затем TV-приложения прошивки,
утилиты — последними. Как только приложение из списка установлено, оно появляется на главном экране само.
`clean.ps1` эти пакеты никогда не отключает.

Режим «Только мои приложения» (включён по умолчанию, выключается в настройках ClearTV): на главном экране и в
сетке только установленные приложения из этого списка; всё остальное ждёт в Настройки → Скрытые приложения
(там же можно вернуть любое). Это скрытие, а не удаление. Удалить лишние приложения, которые ставил
пользователь (не прошивку Сбера), можно отдельным флагом `FULL.cmd -RemoveOtherApps` (`pm uninstall -k --user 0`,
обратимо через `restore.ps1`).

Чего нет на телевизоре, `FULL.cmd`/`START.cmd` скачивают сами — но только из официальных источников самих
разработчиков (`scripts/data/app-sources.json`, шаг `get-apps.ps1`): SmartTube (открытый клиент YouTube для
Android TV — официального YouTube на Салют ТВ нет), Xtra (открытый клиент Twitch), Happ и RUTUBE. Скрипт проверяет,
что итоговый адрес принадлежит домену разработчика и что файл — APK, записывает SHA-256 в
`reports/apps-download.md`, затем `install-apps.ps1` ставит их. Netflix, HBO Max, Apple TV, Spotify и Chrome
официально вне магазинов не раздаются — для них печатается честное пояснение, APK-агрегаторы не используются.
YouTube, Netflix, Spotify, HBO Max, Apple TV, Twitch и Chrome (по решению владельца — через APKMirror): скрипт
открывает страницу в браузере ПК, человек нажимает «Download APK», файл подхватывается из «Загрузок» и ставится
(`.apkm`-бандлы — через `install-multiple` с нужными сплитами). Сторонний клиент Xtra удалён (`retired`).

Веб-карточки: пока приложения Netflix, Spotify, HBO Max, Apple TV или Twitch на телевизоре нет, ClearTV показывает
карточку сервиса, которая открывает его сайт в браузере телевизора (`web_fallbacks` в `favorites.xml`). На
карточке честно написано «веб-версия в браузере»; как только настоящее приложение появится, карточка уступит ему
место. Будет ли сервис играть в браузере — решают DRM, регион и аккаунт сервиса, не лаунчер.

Что работает из России, решает сам сервис, а не лаунчер: RUTUBE и VK Видео — да; YouTube (SmartTube) и Twitch —
насколько пропускает провайдер, Happ с вашей подпиской закрывает блокировки; Netflix, Spotify, HBO Max, Apple TV
в России не обслуживают клиентов, и лаунчер это не изменит.
Свои файлы можно положить в `apps\` вручную (`APPS.cmd`); отключить загрузку — `run-all.ps1 -NoDownload`.
Подробности — `apps/README.md`.

## Телефонные приложения на телевизоре: курсор и полный экран

Служба спец. возможностей ClearTV (та же, что защищает главный экран) даёт курсор для приложений без
поддержки пульта: в любом приложении, кроме ClearTV, удержите OK — появится стрелка; стрелки пульта двигают её
(быстрее при удержании), OK нажимает, двойное нажатие стрелки прокручивает в её сторону, удержание OK убирает
курсор; «Назад» и остальные кнопки работают как обычно. Нажатия выполняются через `dispatchGesture`, содержимое
экрана служба по-прежнему не читает. Выключается в настройках ClearTV. Отдельно `clean.ps1 -PhoneAppsFullscreen`
(входит в FULL): для телефонных сборок (Netflix, Twitch, Chrome, Spotify, YouTube) включает обратимое
переопределение `am compat enable OVERRIDE_ANY_ORIENTATION <пакет>`, чтобы портретное приложение раскладывалось
в ландшафт вместо узкой полосы, и выключает `ignoreOrientationRequest` дисплея, если он был включён; откат —
`restore.ps1`. Браузер для телевизора — TV Bro (качается сам с GitHub разработчика), Chrome остаётся телефонным.

## Полная настройка «как на ролике» (FULL.cmd)

1. `diagnose.ps1` — отчёт и снимок состояния.
2. `install.ps1` — установка и запуск ClearTV.
3. `verify.ps1` — проверки; дальше только если пройдены `installed`, `cold_start`, `dpad_navigation`.
4. `install.ps1 -SetHome` — ClearTV главный экран штатной командой; включается хранитель HOME (ClearTV сам
   вернёт себя главным экраном после перезагрузки через отладку по сети на ТВ; телевизор один раз спросит
   «Разрешить отладку?» от ClearTV — ответить «Всегда»).
5. `clean.ps1 -Mode Recommended -BlockOverlays -Screensaver -HomeGuard` — отключение рекламы, телеметрии и
   мусора Сбера (список: `reports\clean-plan.md`), запрет полноэкранных промо, заставка ClearTV, служба защиты
   главного экрана. Сервисы Сбера (СберTube, Видео, Музыка, магазин…) не трогаются; режим `-Mode Max`
   отключает и их, по явному запросу. Автообновления прошивки не отключаются.
6. Всё записано в `reports\operations-journal.json`; `restore.ps1` возвращает телевизор в исходное состояние.

## Принципы безопасности

- Ни root, ни разблокировки загрузчика, ни прошивки. Системные APK не удаляются.
- Замена главного экрана — только штатным механизмом HOME (`cmd package set-home-activity`); если прошивка его не
  поддерживает, ClearTV остаётся доступным из списка приложений, обходные пути не применяются.
- Любое изменение на телевизоре записывается в `reports/operations-journal.json` вместе с командой отката.
  `restore.ps1` возвращает только то, что реально менялось, и не обещает восстановить то, чего не сохранял.
- Инвентаризация пакетов классифицирует по структурным признакам, не по названиям. CRITICAL и UNKNOWN не трогаем.
  Рекламные компоненты фиксируются по факту показа на экране (`diagnose.ps1 -Capture`), а не по догадкам.
