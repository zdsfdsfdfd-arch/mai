# Подключение к телевизору по ADB

Нужно один раз включить отладку на телевизоре. Названия пунктов на Салют ТВ могут отличаться от
стандартного Android TV; ниже — общий порядок.

1. Узнайте IP-адрес телевизора: Настройки → Сеть (или в роутере). Телевизор и ПК должны быть в одной сети.
2. Включите режим разработчика: Настройки → Система (или «Об устройстве») → несколько раз (обычно 7) нажмите на
   «Номер сборки» / «Версия ПО», пока не появится сообщение о режиме разработчика.
3. В разделе «Для разработчиков» включите «Отладка по USB» и «Отладка по сети» (ADB over network / Network
   debugging). На Android 11+ может быть «Беспроводная отладка» — тогда используйте сопряжение:
   `adb pair 192.168.1.50:XXXXX` с кодом с экрана, затем `adb connect 192.168.1.50:YYYYY`.
4. На ПК: `.\scripts\diagnose.ps1 -Ip 192.168.1.50`. При первом подключении на экране телевизора появится
   запрос «Разрешить отладку по USB?» — отметьте «Всегда» и подтвердите.

## Проверка вручную

```powershell
adb connect 192.168.1.50
adb devices -l
adb shell getprop ro.product.model
```

## Если не подключается

- `unauthorized` — подтвердите запрос на экране ТВ, затем `adb kill-server; adb connect ...`.
- `offline` — выключите и включите отладку по сети на ТВ, проверьте, что IP не изменился.
- Нет ответа на 5555 — отладка по сети выключена или телевизор в другой подсети/VLAN; некоторые прошивки
  отключают ADB после перезагрузки — включите снова.
- Windows может спросить разрешение брандмауэра для adb.exe — разрешите для частных сетей.

Скрипты сами скачивают `adb` (Android SDK Platform Tools с dl.google.com) по флагу `-AutoInstallTools`, если он
не найден в PATH, `ANDROID_HOME` или `%LOCALAPPDATA%\Android\Sdk`.
