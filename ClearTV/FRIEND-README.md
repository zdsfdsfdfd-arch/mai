# Инструкция для того, кто у телевизора

Нужно: телевизор СберТВ (Салют ТВ) и компьютер с Windows 10/11 в одной Wi‑Fi‑сети. Ничего устанавливать
заранее не нужно: скрипт сам скачает маленькую утилиту adb с сайта Google.

1. На телевизоре включите отладку по сети: Настройки → Об устройстве (или Система) → 7 раз подряд нажмите
   на «Номер сборки» (или «Версия ПО») → появится пункт «Для разработчиков» → включите «Отладка по сети»
   (может называться ADB по сети / Network debugging). Там же, в Настройки → Сеть, посмотрите IP‑адрес
   телевизора, например 192.168.1.50.
   Если 7 нажатий ничего не открывают (так на части Салют ТВ с Android 13), напишите тому, кто ведёт проект:
   есть обходные пути (ярлык «Меню разработчика» с флешки), они описаны в `docs/compatibility.md`.
2. Распакуйте архив проекта в любую папку, например `C:\ClearTV`.
3. Дважды щёлкните файл `START.cmd` в папке `ClearTV` (безопасный режим: главный экран не меняется) или
   `FULL.cmd` (полная настройка: ClearTV станет главным экраном, реклама Сбера отключится). Введите IP
   телевизора и нажмите Enter. В FULL-режиме телевизор может ещё раз спросить «Разрешить отладку?» — уже от
   самого ClearTV; тоже «Всегда разрешать».
4. Когда на экране телевизора появится вопрос «Разрешить отладку по USB?», выберите «Всегда разрешать» и ОК.
5. Подождите 3–5 минут. Скрипт: соберёт данные о телевизоре, установит ClearTV и запустит его (вы увидите
   новый главный экран), прогонит проверки пультом сам (экран будет переключаться, это нормально).
6. В конце в папке `ClearTV` появится файл `ClearTV-reports-<дата>.zip`. Отправьте его тому, кто ведёт проект.

В режиме START главный экран телевизора не меняется: ClearTV можно открыть из списка приложений (иконка
ClearTV). В режиме FULL кнопка «Домой» открывает ClearTV; вернуть всё как было можно командой
`scripts\restore.ps1 -Ip <IP>` из той же папки (или попросить того, кто ведёт проект).

Если окно закрылось с ошибкой, сфотографируйте текст или отправьте файл `ClearTV\reports\adb-log.txt`.

Если вы уже запускали прошлую версию: просто распакуйте новый архив поверх (или в новую папку) и запустите
`FULL.cmd` ещё раз. ClearTV обновится сам (`adb install -r`), ничего удалять не нужно. Отладку по сети на
телевизоре снова включать не придётся, пока телевизор не перезагружали; после перезагрузки — включить ещё раз.

Свои приложения (YouTube, Netflix, Twitch, Rutube и т.п.): если у вас есть их установочные файлы `*.apk`,
положите их в папку `ClearTV\apps` до запуска — `FULL.cmd`/`START.cmd` установят их, а ClearTV сам поставит
их первыми на главный экран. Отдельно: `APPS.cmd`. Что можно установить из магазина самого телевизора —
ставьте оттуда, ClearTV их тоже подхватит.

Когда на телевизоре появится вопрос «Разрешить отладку по USB?» уже от самого ClearTV (после того как он стал
главным экраном) — тоже «Всегда разрешать»: так ClearTV удерживает себя главным экраном после перезагрузок.
